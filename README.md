# บ้านในฝัน 3D

เว็บแอปออกแบบบ้านทั้งหลังแบบ 3D:

- **ออกแบบบ้านใหม่**: เลือกชั้นเดียว/2 ชั้น จำนวนห้องนอน ห้องน้ำ แบบหลังคา ระบบวางผังห้อง ประตู หน้าต่าง บันได และจัดเฟอร์นิเจอร์ให้ทุกห้อง
- **บ้านเป็นหลัง**: ผนังหนาจริงที่เจาะช่องประตู/หน้าต่าง หลังคาปั้นหยา/จั่ว/แบน รั้ว โรงจอดรถ ระเบียง ถนนหน้าบ้าน ท้องฟ้า
- **3 มุมมอง**: ภายนอก · ภายใน (ยกหลังคา ตัดผนังอัตโนมัติ เลือกชั้น) · เดินชม (เดินแบบเกม ประตูเปิดเองเมื่อเดินเข้าใกล้ ขึ้นบันไดได้)
- **เวลาของวัน**: แดดเช้า-เย็น เงา และไฟในบ้านตอนกลางคืน
- **แสงสมจริง**: โคมไฟทุกชิ้นเป็นแหล่งแสงจริง ปรับความสว่าง (ลูเมน) สีแสง (2700–6500K) และเปิด/ปิดได้ · โคมที่เลือกจะทอดเงาให้เห็นทันที · มีเงาสัมผัส (ambient occlusion) และแสงฟุ้ง (bloom)
- **ภาพสมจริง (path tracing)**: คำนวณแสงที่เด้งสะท้อนจากทุกพื้นผิว เงานุ่ม สีสะท้อนข้ามผนัง แล้วบันทึกเป็น PNG ได้
- แคตตาล็อกของแต่งที่มีรูปและตัวอย่าง 3D ทุกชิ้น · สร้างห้องจากรูปถ่าย · สรุปวัสดุและงบทั้งหลัง (รวมหลังคา สีภายนอก รั้ว)

## เริ่มใช้งาน

```bash
npm install
npm run dev        # เปิด http://localhost:5173
```

```bash
npm test           # unit tests (คำนวณมุมกล้องจากรูป, ปริมาณวัสดุ)
npm run build      # type-check + build ไปที่ dist/
npm run preview    # เปิดดูไฟล์ build
```

## นำขึ้นเว็บ

`npm run build` ได้ไฟล์ static ใน `dist/` (ใช้ path แบบ relative) นำไปวางที่ไหนก็ได้:

- **Vercel / Netlify / Cloudflare Pages**: build command `npm run build`, output `dist`
- **GitHub Pages / โฮสติ้งทั่วไป**: อัปโหลดโฟลเดอร์ `dist/` ทั้งโฟลเดอร์

ไม่มี backend ข้อมูลบ้านเก็บใน localStorage ของเบราว์เซอร์ รูปถ่ายไม่ถูกอัปโหลดหรือบันทึกที่ไหน

## โครงสร้าง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `src/lib/walls.ts` | หาผนังจากขอบห้อง (ผนังกั้นห้อง / ผนังภายนอก) และเจาะช่องประตูหน้าต่าง |
| `src/lib/shell.ts` | ขนาดหลังคา ผนังภายนอก รั้ว ที่ดิน |
| `src/engine/structure.ts` | สร้างผนัง หลังคา พื้นชั้นบน โรงจอดรถ ราวระเบียง รั้ว ถนน |
| `src/lib/kelvin.ts` | แปลงอุณหภูมิสี (K) เป็นสีแสง |
| `src/engine/walk.ts` | โหมดเดินชม: ชนผนัง ลอดประตู ขึ้นบันได |
| `src/data/generate.ts` | ออกแบบผังบ้านอัตโนมัติ + จัดเฟอร์นิเจอร์ตามประเภทห้อง |
| `src/engine/Engine.ts` | ฉาก three.js: ห้อง, ของ, กล้อง, View Cube, ลากวาง, ตัดผนังอัตโนมัติ, โหมดรูปถ่าย, render เฉพาะเมื่อมีการเปลี่ยน |
| `src/engine/thumbs.ts` | สร้างรูปตัวอย่างของในแคตตาล็อกจากโมเดล 3D จริง แล้ว cache ไว้ |
| `src/data/catalog.ts` | โมเดลของแต่ง 45 ชิ้น แยก 9 หมวด พร้อมขนาดและราคา |
| `src/data/surfaces.ts` | ลายพื้น/ผนังแบบ procedural พร้อม normal/roughness map และราคา |
| `src/data/templates.ts` | ประเภทห้องและแบบบ้านเริ่มต้น |
| `src/lib/pose.ts` | คำนวณมุมกล้องและขนาดห้องจากจุดมุมในรูปถ่าย |
| `src/lib/boq.ts` | ปริมาณวัสดุและงบประมาณ |
| `src/store.ts` | state (zustand) + undo/redo + บันทึกอัตโนมัติ |
